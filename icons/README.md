| 파일명 | 크기 | 쓰임 |
| --- | --- | --- |
| `icon-192.png` | 192 × 192 | 홈 화면 아이콘 · 브라우저 탭 아이콘(favicon) |
| `icon-512.png` | 512 × 512 | 홈 화면 아이콘(고해상도) · 실행 화면 |

넣어 두면 갤럭시 홈 화면에서 모서리가 잘리지 않습니다.
