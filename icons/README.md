# 홈 화면 아이콘

| 파일명 | 크기 | 쓰임 |
| --- | --- | --- |
| `icon-192.png` | 192 × 192 | 홈 화면 아이콘 · 브라우저 탭 아이콘(favicon) |
| `icon-512.png` | 512 × 512 | 홈 화면 아이콘(고해상도) · 실행 화면 |
| `icon-maskable-512.png` | 512 × 512 | 갤럭시/안드로이드가 아이콘을 동그랗게 잘라도 안전하도록 여백을 둔 버전 |
| `icon-source.webp` | 1254 × 1254 | 원본 이미지 (위 3개를 만든 원본) |

세 PNG 는 `icon-source.webp` 에서 자동으로 만든 것입니다. 원본을 바꾸거나 크기를 다시 맞추려면

```
node tools/make-icons.js
```

- `icon-192.png` · `icon-512.png` : 남색 사각형 부분만 잘라내 모서리 바깥은 투명 처리
- `icon-maskable-512.png` : 배경을 남색(#3C5C93)으로 꽉 채우고 그림은 가운데 80%(사방 51px 여백) 안에 배치
